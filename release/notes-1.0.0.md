## 车载AirPlay / CarAirPlay 1.0.0

首个正式版本，已在实车测试通过。 · First release, tested on a real head unit.

**中文**
- AirPlay 2 屏幕镜像、视频、音乐投送（基于 UxPlay / android-airplay-server）
- 支持 Android 6.0+，内置 arm64-v8a / armeabi-v7a / x86 / x86_64
- 「车机」页：热点名称、密码、2.4G/5G 设置与一键开关；Root 与临时热点备选
- 开机 / ACC 上电 / 休眠唤醒自动启动，启动延迟、后台保活、网络变化自动重新广播
- 横屏侧边导航、中文界面

**English**
- AirPlay 2 screen mirroring, video and audio (based on UxPlay / android-airplay-server)
- Android 6.0+, ships arm64-v8a / armeabi-v7a / x86 / x86_64
- "Car" tab: hotspot SSID, password, 2.4/5 GHz and one-tap on/off; root and local-only fallbacks
- Autostart on boot / ACC on / wake from sleep, start delay, keep-alive, re-advertising on network change
- Landscape side navigation, Chinese and English UI
